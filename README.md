# Forecast-power-supply-demand
# ⚡ PJMW Hourly Energy Consumption Forecasting

## 📌 Project Overview

The **PJMW Hourly Energy Consumption Forecasting** project focuses on analyzing historical electricity consumption data and predicting future power demand using time series forecasting techniques.

The main objective is to understand electricity consumption patterns, identify trends and seasonal variations, and forecast future energy demand. This project can help in better electricity planning, power supply management, and resource optimization.

## 🎯 Objectives

- Analyze historical hourly electricity consumption.
- Identify daily, weekly, and seasonal consumption patterns.
- Perform Exploratory Data Analysis (EDA).
- Clean and preprocess the dataset.
- Understand long-term energy consumption trends.
- Forecast future electricity demand.
- Deploy an interactive forecasting application using Streamlit.

## 📊 Dataset

- **Dataset:** PJMW Hourly Energy Consumption
- **Data Type:** Time Series Data
- **Frequency:** Hourly
- **Target Variable:** Energy Consumption
- **Source:** PJM Interconnection / Kaggle dataset.

The dataset contains historical electricity consumption values recorded at hourly intervals.

## 🛠️ Technologies Used

- **Programming Language:** Python
- **Libraries:** Pandas, NumPy, Matplotlib, Seaborn, Scikit-learn
- **Data Analysis:** Exploratory Data Analysis (EDA)
- **Forecasting:** Time Series Forecasting
- **Deployment:** Streamlit
- **Development Tools:** Jupyter Notebook, VS Code, Git, GitHub

## 🔍 Project Workflow

1. **Data Collection:** Collected historical PJMW electricity consumption data.
2. **Data Cleaning:** Handled missing values, checked duplicates, and prepared the dataset.
3. **Exploratory Data Analysis:** Analyzed consumption distribution, hourly patterns, daily and weekly trends, and long-term trends.
4. **Holiday Analysis:** Studied energy consumption patterns during holidays.
5. **Data Visualization:** Created graphs to understand electricity demand patterns.
6. **Model Development:** Applied time series forecasting techniques to predict future electricity consumption.
7. **Deployment:** Developed an interactive Streamlit application to generate future energy demand forecasts.

## 📈 Key Analysis

- Hourly electricity consumption patterns.
- Daily and weekly consumption trends.
- Long-term energy demand trends.
- Holiday-based consumption analysis.
- Data quality and missing value analysis.
